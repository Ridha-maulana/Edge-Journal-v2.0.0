# Update Jurnale v2.4.2

Perubahan utama pada update ini:

- Kontrol **Periode** berada di dalam detail **Advanced Statistics** dan **Trader DNA** masing-masing.
- Urutan kartu Advanced Statistics menjadi **Kalender → Monthly gain → Growth**.
- Grafik Monthly gain menampilkan persentase tiap bulan; profit berwarna hijau dan rugi berwarna merah.
- Basis source mengikuti arsip aplikasi v2.4.1 yang menyertakan sinkronisasi Firebase.

Untuk update manual di GitHub, unggah file yang disertakan dalam paket ini dan timpa file dengan nama yang sama. Jika repository GitHub Anda sudah memiliki `cloud-sync.js`, `firebase-config.js`, `PANDUAN_FIREBASE.md`, dan `GITHUB_UPLOAD.md` dari versi sebelumnya, file yang wajib ditimpa untuk perubahan UI ini adalah `index.html`; `TODO.md` dan dokumen update hanya bersifat catatan.
